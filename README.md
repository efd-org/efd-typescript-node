# efd-typescript-node

Simple TypeScript/Node.js hello-world starter project.

## Build
```bash
npx tsc -p tsconfig.json
```

This compiles the TypeScript source into JavaScript and writes the output to the `dist/` directory for deployment as a Node.js application.

## Run
```bash
node src/index.js
```

Expected output:
```text
Hello, World!
```

## Test
```bash
node --test test/index.test.js
```
